GSC Bulk URL Removal

Массовая отправка URL на удаление из выдачи Google через Search Console — бесплатно и без лимитов по количеству адресов.

Что это

Расширение для Chrome, которое автоматизирует раздел «Индекс → Удаления» в Google Search Console. Вместо того чтобы отправлять каждый URL вручную, вы вставляете список — и расширение само заполняет и отправляет запрос для каждого адреса.

Возможности

  • До 1000+ URL за один запуск;
  • вставка списка или загрузка файла .txt / .csv;
  • режимы «Временно удалить URL» и «Очистить кеш URL»;
  • область: один URL или все URL с префиксом;
  • пауза, продолжение и остановка в любой момент;
  • автопродолжение очереди после перезагрузки страницы;
  • журнал ошибок и экспорт результата в CSV;
  • панель прогресса прямо на странице Search Console.

Как начать

  • Установите расширение из Chrome Web Store.
  • Откройте Search Console → нужный ресурс → Индекс → Удаления.
  • Нажмите иконку расширения, вставьте URL и нажмите «Старт».

Приватность

Расширение работает полностью локально: никакие данные не собираются и никуда не отправляются. Подробнее — в политике конфиденциальности.

Поддержка

Вопросы и сообщения об ошибках — через вкладку «Поддержка» на странице расширения в Chrome Web Store. Перед обращением проверьте: страница Search Console открыта и обновлена после установки расширения, у Google есть дневные лимиты на запросы удаления — при массовых ошибках увеличьте задержку в настройках.

English

GSC Bulk URL Removal is a free Chrome extension that bulk-submits URL removal requests via the Removals tool in Google Search Console: 1000+ URLs per run, pause/resume, auto-recovery after page reload, CSV export. Fully local — no data is collected or sent anywhere. Support: via the "Support" tab on the Chrome Web Store listing.
