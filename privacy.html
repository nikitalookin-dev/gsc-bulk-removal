Политика конфиденциальности — GSC Bulk URL Removal

Дата обновления: 3 ноября 2026 г.

Коротко

Расширение GSC Bulk URL Removal не собирает, не хранит, не передаёт и не продаёт никакие пользовательские данные. Вся обработка происходит исключительно в браузере пользователя. У расширения нет серверной части, аналитики, трекеров и внешних запросов.

Какие данные обрабатываются

Расширение обрабатывает только данные, которые пользователь вводит сам:

  • Список URL, вставленный пользователем для отправки запросов на удаление в Google Search Console;
  • Настройки запуска (режим, область, задержка);
  • Журнал выполнения (статусы отправки по каждому URL).

Эти данные сохраняются только локально, в chrome.storage.local на устройстве пользователя, и используются исключительно для работы расширения: автоматизации диалога «Создать запрос» на странице Google Search Console и отображения прогресса.

Передача данных третьим лицам

Данные никуда не передаются. Единственные сетевые взаимодействия — это действия, которые расширение выполняет на открытой пользователем странице Google Search Console (search.google.com) от имени и по инициативе пользователя.

Разрешения

  • storage — локальное хранение очереди URL, настроек и журнала;
  • доступ к search.google.com — автоматизация интерфейса раздела «Удаления».

Удаление данных

Кнопка «Сбросить» в окне расширения полностью удаляет сохранённое состояние. Удаление расширения удаляет все его локальные данные.

Контакты

По вопросам конфиденциальности напишите владельцу расширения через страницу поддержки в Chrome Web Store.

Privacy Policy — GSC Bulk URL Removal

Last updated: November 3, 2026

Summary

GSC Bulk URL Removal does not collect, store, transmit, or sell any user data. All processing happens entirely inside the user's browser. The extension has no backend, no analytics, no trackers, and makes no external network requests.

Data processed

The extension only processes data the user explicitly provides:

  • The list of URLs the user pastes to submit removal requests in Google Search Console;
  • Run settings (mode, scope, delay);
  • The execution log (per-URL submission statuses).

This data is stored only locally in chrome.storage.local on the user's device and is used solely to operate the extension: automating the "New request" dialog on the Google Search Console Removals page and showing progress.

Third-party sharing

No data is shared with anyone. The only network interactions are the actions the extension performs on the Google Search Console page (search.google.com) opened by the user, on the user's behalf and at the user's initiative.

Permissions

  • storage — local storage of the URL queue, settings, and log;
  • Access to search.google.com — automating the Removals UI.

Data removal

The "Reset" button in the extension popup wipes all saved state. Uninstalling the extension removes all of its local data.

Contact

For privacy questions, contact the extension owner via the support page on the Chrome Web Store.
